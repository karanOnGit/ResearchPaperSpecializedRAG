# Attention Is All You Need: Architecture & Retrieval

## Introduction
The dominant sequence transduction models are based on complex recurrent or convolutional neural networks that include an encoder and a decoder. The Transformer is the first transduction model relying entirely on self-attention to compute representations of its input and output without using sequence-aligned RNNs or convolution.

## Transformer Architecture
The Transformer follows an encoder-decoder structure using stacked self-attention and point-wise, fully connected layers. 

### Multi-Head Attention
Multi-Head Attention allows the model to jointly attend to information from different representation subspaces at different positions. Instead of performing a single attention function with d-dimensional keys, values, and queries, we linearly project queries, keys, and values h times with different, learned linear projections.

Multi-Head Attention implements Scaled Dot-Product Attention in parallel. It uses the softmax function to compute attention weights over value vectors.

### Positional Encoding
Since our model contains no recurrence and no convolution, in order for the model to make use of the order of the sequence, we must inject some information about the relative or absolute position of the tokens in the sequence. To this end, we add Positional Encodings to the input embeddings at the bottoms of the encoder and decoder stacks.

## Knowledge Retrieval and Object Modeling
In modern neural architectures, dense vector representations generated by the Transformer enable Semantic Search across large corpora. By storing representations in a Vector Index and linking them with structured metadata in MongoDB, researchers can construct Hybrid Retrievers that combine dense embeddings with structured concept graphs.
